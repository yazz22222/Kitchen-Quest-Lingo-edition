# Kitchen-Quest-Lingo-edition
Explore the Kitchen environment and you will learn the names of 10 everyday kitchen objects in Bahasa Melayu (Malay), test your knowledge in a picture style quiz.

## General Information

My project is a 2D style language learning game where players explore the kitchen environment and learn the names of 10 everyday kitchen items in Bahasa Melayu (Malay). Players can then enter a picture style quiz section to refine their knowledge. My game does not aim to necessarily solve a problem, however it is a creative display of how I can make language learning fun and interactive. I created this project as a cute and fun way to learn my native language, and i hope others can learn it to.
